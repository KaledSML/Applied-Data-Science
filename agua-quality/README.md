# 💧 Análisis de potabilidad del agua

Proyecto académico de análisis de datos y Machine Learning para explorar las características fisicoquímicas del agua y predecir su potabilidad mediante modelos de clasificación.

## 🛠️ Herramientas
- Python · Pandas · NumPy
- Matplotlib · Seaborn
- Scikit-learn · XGBoost
- Google Colab

## 🔎 ¿Qué se hizo?
- Exploración y limpieza de datos faltantes.
- Visualización de distribuciones y correlaciones.
- Balanceo de clases mediante sobremuestreo.
- Entrenamiento y comparación de siete modelos de clasificación.
- Evaluación de resultados mediante métricas de clasificación.

## 📊 Resultados
Los modelos con mayor accuracy en la ejecución original fueron Random Forest y Bagging Classifier, ambos con un **89 %**.
