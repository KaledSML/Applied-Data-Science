# 🌸 Clasificación de flores Iris

Proyecto académico de Machine Learning para explorar el conjunto de datos Iris y clasificar flores según las medidas de sus sépalos y pétalos.

## 🛠️ Herramientas
- Python · Pandas
- Scikit-learn
- Google Colab

## 🔎 ¿Qué se hizo?
- Exploración y análisis estadístico de 150 registros.
- Codificación de las especies mediante `LabelEncoder`.
- Entrenamiento de modelos de clasificación: Regresión Logística, K-Nearest Neighbors y Árbol de Decisión.

## 📊 Resultados
- **K-Nearest Neighbors:** accuracy de entrenamiento del 96,3 %.
- **Árbol de Decisión:** accuracy de entrenamiento del 100 %.
- **Regresión Logística:** pruebas de predicción sobre nuevos registros.

## 📝 Nota
Ejercicio académico introductorio de clasificación supervisada. Las métricas corresponden al conjunto de entrenamiento, por lo que no representan necesariamente el rendimiento de los modelos con datos nuevos.
