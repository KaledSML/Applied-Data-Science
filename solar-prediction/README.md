# ☀️ Predicción de radiación solar

Proyecto académico de análisis de datos y Machine Learning para estudiar variables meteorológicas y predecir la radiación solar mediante modelos de regresión.

## 🛠️ Herramientas
- Python · Pandas · NumPy
- Matplotlib · Seaborn · Bokeh
- Scikit-learn
- Google Colab

## 🔎 ¿Qué se hizo?
- Exploración y visualización de variables meteorológicas.
- Análisis de correlaciones mediante Pearson.
- Selección de características relevantes.
- Entrenamiento de un modelo `RandomForestRegressor`.
- Validación cruzada y comparación entre valores observados y predichos.

## 📊 Resultados
El modelo final utilizó temperatura, día del año y hora del día como variables predictoras.

- **R² en validación cruzada:** 93,43 %
- **R² en el conjunto de prueba:** 93,66 %
- **MSE:** 6417,25
