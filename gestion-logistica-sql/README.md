# 🎁 Base de datos: Cajas Navideñas

Proyecto académico de diseño e implementación de una base de datos relacional para gestionar empleados, empresas, sucursales, cajas navideñas y facturación.

## 🛠️ Herramientas
- Microsoft SQL Server · T-SQL
- SQL Server Management Studio (SSMS)
- SAP PowerDesigner

## 🔎 ¿Qué se hizo?
- Modelado conceptual y físico de la base de datos.
- Creación de tablas, claves primarias y foráneas.
- Definición de relaciones e índices.
- Desarrollo de procedimientos almacenados para consultar empleados, facturas e historiales de compra.

## 📝 Nota
Proyecto académico enfocado en el modelado relacional y las consultas SQL, conservado como parte de mi proceso de aprendizaje.
