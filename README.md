# 📊 Applied Data Science

Repositorio de proyectos y trabajos académicos relacionados con el análisis de datos, el aprendizaje automático y las bases de datos.

Aquí reúno ejercicios realizados durante mi proceso de aprendizaje, explorando distintas herramientas y técnicas para trabajar con datos. Algunos proyectos conservan decisiones y errores propios de su desarrollo original, como parte de mi evolución y aprendizaje.

## 📂 Proyectos

| Proyecto | Descripción | Herramientas principales |
|---|---|---|
| 💧 [Análisis de potabilidad del agua](./agua-quality/) | Análisis de datos y comparación de modelos para clasificar la potabilidad del agua. | Python, Pandas, Scikit-learn |
| 🌸 [Clasificación de flores Iris](./clasificacion-iris/) | Exploración del dataset Iris y aplicación de modelos de clasificación. | Python, Pandas, Scikit-learn |
| ☀️ [Predicción de radiación solar](./solar-prediction/) | Análisis de variables meteorológicas y entrenamiento de un modelo de regresión. | Python, Pandas, Scikit-learn |
| 🎁 [Gestión logística SQL](./gestion-logistica-sql/) | Diseño de una base de datos relacional y desarrollo de consultas y procedimientos almacenados. | SQL Server, T-SQL, PowerDesigner |

## 🛠️ Herramientas y tecnologías

- **Lenguajes:** Python, SQL.
- **Análisis y visualización:** Pandas, NumPy, Matplotlib, Seaborn, Bokeh.
- **Machine Learning:** Scikit-learn, XGBoost.
- **Bases de datos:** Microsoft SQL Server.
- **Entorno de trabajo:** Google Colab, SQL Server Management Studio.

## 📝 Nota

Este repositorio reúne trabajos académicos de distintas etapas de mi aprendizaje. La idea es conservarlos como registro de mi experiencia, reconocer sus limitaciones y mostrar mi progreso en el análisis de datos.
